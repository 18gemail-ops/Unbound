Core capabilities

Everyday features, made easy to understand

Not a pile of features — every step has a clear entry point, a clear status and a plain-language explanation.

Subscription management and auto-update

Import a subscription with a single link and see usage and expiry right on the card. Set auto-update every 1–24 hours; when an update finishes, the config reloads automatically and a system notification is sent.

Per-process routing

Send your browser through one line and your games through another. Bind by process name or full path; picking two or more lines forms a load-balance group automatically, with round-robin or session-persistent policies.

Chained proxy

Assign a front proxy to a restricted node so traffic goes through the relay first. Set it with the chain button on the node card; latency is simply the sum of both hops.

Merge override + extension script

When you don't want to touch the original subscription, deep-override any config field with a Merge snippet. For bulk edits, the built-in QuickJS engine runs one extension script — rename nodes, add rules, all from a dialog.

Desktop floating window

Live speed, current node latency and active connections stay on your desktop. 3 sizes, 3 layouts, 7 color themes — with mouse pass-through and drag anywhere.

Network rescue kit

When the proxy exits unexpectedly and your browser can't open pages, Diagnostics pinpoints the problem first, then one click resets the system proxy and flushes the DNS cache, with an automatic re-check.

About configuration

Subscriptions, overrides, scripts — three layers, each minding its own business

Subscriptions stay pristine and follow upstream updates while your personal changes live in separate files — no overwriting. Swap subscriptions or providers without reconfiguring everything.

  • Profiles: http/https subscription links, drag to reorder, rename, generate a QR code to share with your phone, and view live usage.
  • Merge override: a few lines override fields in the subscription (except app-level settings such as port and mode), deeply merged recursively when the runtime config is generated.
  • Extension script: built-in QuickJS engine — one main(config) function batch-renames nodes and adds or removes rules.
  • Runtime config: app-level fields such as port, secret and mode are injected by the client and never overridden by subscriptions; config changes hot-reload automatically — no manual core restart.

App Routing

Let every app take its own route

No need to switch everything to global for one game. Bind lines by process name or full path; all other traffic keeps following the rules.

  • Easy to pick: choose straight from processes currently using the network, with app icons — no need to remember exe names.
  • Flexible binding: one line goes directly to that group; two or more lines form a load-balance group so multiple lines serve the same app together.
  • Load-balance policies: round-robin spreads connections across lines; session-persistent keeps a session on one line.
  • Visible results: the binding list shows the app's live up/down speed — one glance tells whether it's working.

When things go wrong

First it tells you what's wrong, then it helps you fix it

Diagnostics runs 11 checks in order: core status, port listening, system proxy, DNS resolution, DNS takeover, direct exit, proxy exit, WebRTC leaks, current node, direct GitHub access and config loading. Each check gives a conclusion and a suggested next step.

One-click rescue

Reset the system proxy and flush the DNS cache — neither needs admin rights and both take effect instantly, enough to fix the most common failure: "browser can't open pages after the proxy exits".

Targeted repairs

Leftover system proxy settings, DNS servers set to 0.0.0.0, abnormal hosts files, damaged network stacks — each has its own repair button; operations needing admin rights are clearly marked and go through UAC elevation.
