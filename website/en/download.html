Only get installers from the official releases page

Downloads live on the GitHub Releases page. The installer requests network and file read/write permissions — verify the source is trustworthy before installing.

Before you install

  • 64-bit Windows 10 or Windows 11.
  • The system proxy needs no extra privileges; TUN mode requires admin rights and will show a UAC prompt.
  • If another client using the same core is installed on the machine, exit one of them first to avoid control port conflicts.
  • Default ports: mixed proxy 7890, control API 9090 — changeable in Settings.

After installing

  • Add a subscription under Profiles first, then flip the enable switch on its card.
  • Turn on the system proxy under Settings → General → System integration.
  • Return to the Dashboard to confirm the core is running and nodes show latency values.
Installation steps

Three steps to install, five to be productive

Download the installer

Open the official releases page and download the Windows installer from the latest release (file names look like Unboundlink_x.x.x_x64-setup.exe).

Run the setup wizard

Double-click the installer, choose a location and click Next through the wizard. Stick to the default directory — avoid paths with Chinese or special characters.

First launch

Launch it from the Start menu or desktop icon. If a previous version's data directory is found, settings and subscriptions migrate automatically — no manual file copying.

Import a subscription and enable it

Profiles → Add subscription → paste the http/https link → OK; back on the card flip the enable switch (multiple subscriptions can be on at once).

Turn on the system proxy

Enable the system proxy under Settings → General → System integration, then check the Dashboard — download and upload figures should start moving.

Data and uninstall

Where your data lives, and how to take it with you

Data directory

Configs, subscriptions and the core's working directory live under %APPDATA%\com.unboundlink.desktop, containing settings, the subscription index and originals, Merge overrides, extension scripts, the generated runtime config, dashboard files, rule hit statistics and traffic history.

View and copy the data directory path under Settings → About.

Backup, migration and uninstall

Before switching computers, use Settings → Maintenance → Backup and restore → Export backup to get a JSON file; import it in the new environment to restore settings, subscriptions, Merge config and core version records.

Uninstalling doesn't delete the data directory; to clean up completely, delete the directory manually after uninstalling.

Remember to turn off the system proxy before uninstalling

First disable the system proxy under Settings → General → System integration, or reset it via Diagnostics → Network rescue → One-click rescue, so your browser doesn't keep pointing at a local proxy port that no longer exists after uninstall.
