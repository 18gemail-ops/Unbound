User Guide

Dashboard

The Dashboard is the first screen you see after opening the client — check the overall status at a glance and switch proxy groups and nodes right there.

What this page solves

Its role is the overview: is the core running, is traffic flowing normally, which node is active. The two most common everyday actions — check that you're connected and temporarily switch lines — both happen here, without visiting the Proxies page.

Core status

The core status card at the top shows whether the core is running, plus its version, memory usage and uptime — read by the client from the core so you can judge the background process's health. The sidebar footer also shows live "Core memory" and "App memory" usage, visible from anywhere.

  • Running: the core is working; proxying is available.
  • Not running: the core is down; the system proxy and nodes can't work.

Traffic section

The traffic section gives three summary figures and a live traffic chart:

ItemMeaning
Total downloadTotal traffic received since the core started this time.
Total uploadTotal traffic sent since the core started this time.
Active connectionsThe number of connections in progress; jump to Connections for details.
Live traffic chartInstant up/down speed trends, pushed from the core over WebSocket.
Moving curves mean data is flowing

Open a webpage or video and the curve should ripple while total download grows.

Switching proxy groups and nodes

The lower part of the Dashboard holds the proxy group / node switch rows. Each proxy group gets a row where you can pick its current node right here:

  • Open a group's dropdown, pick a node, and the change takes effect immediately.
  • For speed tests, favorites or finer filters, head to the Proxies page.

A subscription usually has several proxy groups, like "Select" or "Auto Select". What you switch here is the group's current node; if the group uses an automatic policy it picks for itself, and a manual choice overrides the automatic result.

Common uses

TaskHow to read / do it here
Check that you're connectedSee whether total download / upload has values that grow while you browse, and confirm the current node shows a latency number.
Temporarily switch linesPick another node in the group's dropdown — no need to leave the page.
Confirm the core is healthyCheck the status card says Running and that uptime accumulates normally.
When the core shows as not running

First check Settings to confirm "auto-start core" is on; if it is but the core still isn't running, head to Diagnostics to find the problem.
