User Guide

User Guide overview

This guide walks through the client's 11 feature pages one by one: what each page does, how to fill in parameters, and how to recover if something breaks. First-time users should start with "Install and first run".

Five-minute path to get started

Install → import a subscription → flip its enable switch → turn on the system proxy → confirm on the Dashboard that the node is connected. Just five steps.

A few terms first

Later chapters use these words constantly — take a minute to get familiar:

TermMeaning
CoreThe program doing the real work (mihomo). It's installed with the app; the client starts, supervises and stops it — you never install or configure it separately.
SubscriptionAn http/https link that opens to a YAML config containing nodes, policy groups and rules. The client downloads it as the raw material for generating the runtime config.
Node / proxy groupA node is a single line; a proxy group is a set of nodes that can auto-select by latency, switch manually or fail over.
RuleThe basis for deciding which line traffic takes. If nothing matches down to the last rule, the subscription's fallback policy applies (usually MATCH).
System proxyModifies Windows Internet settings so programs that honor the system proxy (browsers, most desktop software) use it automatically. Requires the core to be running.
TUN modeCreates a virtual adapter to take over all traffic at the network layer, covering apps that ignore the system proxy (some games, command-line tools). Requires admin rights.
Runtime configThe config.yaml the client assembles from "subscription + your overrides + app-level settings" — the file the core actually reads. You never edit it directly.

Where every setting lives

Can't find a switch? Check this table first — almost every switch lives in one of Settings' six tabs:

TabWhat it covers
AppearanceTheme, language, pause rendering when unfocused, Proxies page columns, hide timed-out nodes, theme customization (colors / fonts / custom CSS).
SystemSystem proxy (with bypass list and terminal proxy commands), launch at startup, silent start, start page, startup script, tray click action, three-state tray icons, minimize to tray on close, traffic floating window, floating window mouse pass-through, system notifications, core watchdog, check for updates on launch, clear connections on node switch, system proxy guard, global shortcuts.
NetworkPorts and mode (mixed proxy port, control port, mode, log level), kernel behavior (auto-start core, allow LAN, IPv6, unified delay), web dashboard (with control secret), TUN mode, custom DNS (with fallback DNS and static Hosts), speed test and health (scheduled latency tests, node health monitoring, auto-switch on failure), network environment (automatic system-proxy and mode switching by Wi-Fi name).
ToolsUWP App Tool, GeoData databases, traffic tunnel, node cleanup.
MaintenanceSubscription auto-update interval, core updates, node test URL and timeout, app logs, backup and restore (including export diagnostics).
AboutApp logo and name, app version, core version, data directory (openable in one click), help and support (website and online user guide), developer tools, quit the app.
Settings apply instantly

Every setting saves immediately — no "OK / Apply" buttons. Core-related changes (ports, TUN, DNS) hot-reload or restart the core automatically, and switches in the UI reflect the actual state.
