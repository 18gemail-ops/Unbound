User Guide

Install and first run

From downloading the installer to confirming nodes are connected, this page lays out the complete order. Complete the "five steps of first run" below and the client is ready to use.

System requirements

ItemRequirement
Operating systemWindows 10 / 11, 64-bit.
PrivilegesTUN mode requires admin rights; enabling the system proxy likewise requires admin rights. If you only use the system proxy day to day, you can start with normal privileges and relaunch as administrator when you run into permission issues.
CoreNo need to install the mihomo core yourself. The installer already bundles the mihomo core and the wintun TUN driver; the client starts and supervises them.

Installation

Open the download page, get the Windows installer (NSIS format) from Releases, double-click it and follow the prompts. The current version is 0.1.1.

On first run, if the data directory doesn't exist, the client tries migrating old configs from historical directory names so users upgrading from older versions keep their subscriptions and settings.

Just use the default directory

Keep the default directory the installer suggests; don't change it to another location.

First-run guide

On a fresh install, the first launch opens a four-step guide that walks you through the initial setup:

  1. Welcome — a one-line intro to the app: subscription management, rule-based routing and traffic insights all happen locally, with no account needed.
  2. Import a subscription — paste your subscription link right in the guide to import it, or skip and add one later under Profiles.
  3. Quick setup — three recommended toggles: launch at login, system notifications and the core watchdog; change them anytime in Settings.
  4. Get started — a few handy tips: Ctrl+K opens the command palette, closing the window minimizes to the tray, and Diagnostics checks your network in one click.

Every step has a Back button; after you click Skip or finish the guide it won't pop up again. Users upgrading from older versions are unaffected and won't see it.

The five steps of first run

  1. Go to Profiles, click "Add subscription" top-right, paste your http/https link (name can be left blank — the client detects it), and click OK.
  2. Flip the enable switch on the new subscription card (the first subscription is enabled automatically). A blue "In use" badge appears once it's on — multiple subscriptions can be enabled at the same time.
  3. Open Settings → Network and confirm "auto-start core" is on (on by default). The core then starts by itself whenever needed — no manual action required.
  4. Open Settings → General → System integration and turn on the "system proxy".
  5. Return to the Dashboard, confirm the core status is Running and the current node shows a latency number.

Three ways to route traffic through the proxy

The client never forces a full takeover — choose the scope you need:

MethodBest forNotes
System proxyThe least hassle; covers browsers and most desktop programs.Modifies Windows Internet settings; requires the core to be running.
TUN modeFull traffic takeover, covering apps that ignore the system proxy (some games, command-line tools).Requires admin rights.
App RoutingOnly chosen apps use the proxy; everything else stays direct.Add per-app rules on the App Routing page.

Data directory and backup

All runtime data lives in %APPDATA%\com.unboundlink.desktop, mainly:

File / directoryContents
settings.jsonAll settings.
profiles.jsonThe subscription index.
profiles\{id}.yamlThe original YAML of each subscription.
merge.yamlMerge overrides.
script.jsExtension scripts.
config.yamlThe generated runtime config — the file the core actually reads.
ui\Static files for the built-in web dashboard.
rule_stats.json / traffic_history.jsonRule hit statistics and traffic history.
core_version.txtCore version records.

Before migrating machines or reinstalling, open Settings → Maintenance → Backup and restore to export and import a JSON backup. It contains settings, subscriptions, Merge config and the core version.

Two more things

The app is single-instance — launching it again returns to the existing window. The main window, floating window and tray panel all hide rather than exit when closed; to really quit, use Settings → About → Quit.
