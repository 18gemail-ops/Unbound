User Guide

Advanced tips

This page collects six handy techniques: fine-tune subscriptions with Merge and scripts, create quick rules for domains, route restricted nodes through a relay, jump around with the command palette, and get the floating window and shortcuts set up your way.

How to use Merge override

On the Profiles page, open "Global override config" and write a YAML snippet in the editor. When the runtime config is generated, the snippet is deeply merged recursively with the subscription to override its fields — write only what you want to change; no need to copy the whole config, and subscription updates remain unaffected.

Don't put port, control secret, mode or log level here

These are app-level settings written by the client when generating the config, overriding same-named entries in Merge. Change them under Settings → Network → Ports and mode.

The snippet below does three things at once: enables unified delay, appends a dns block, and adds a node to the proxy group named "Manual switch".

unified-delay: true

dns:
  enable: true
  nameserver:
    - 223.5.5.5

proxy-groups:
  - name: Manual switch
    type: select
    proxies:
      - HK Node 01

Extension script examples

"Global extension script" on the same page accepts QuickJS scripts in the editor; the script must implement main(config) and return config. It runs on the built-in QuickJS engine to batch-rename nodes and add or remove rules. The two snippets below can be pasted as-is.

Example 1: strip ads from node names.

function main(config){
  config.proxies.forEach(p => {
    p.name = p.name.replace(/official|subscribe/gi, "")
  })
  return config
}

Example 2: add a uniform prefix to all node names.

function main(config){
  config.proxies.forEach(p => {
    p.name = "[U] " + p.name
  })
  return config
}

Quick rules

On the Connections page, right-click a connection and choose "direct for this domain" or "route this domain through a chosen line". The client generates a DOMAIN-SUFFIX rule, inserted at the top of the rule list — higher priority than subscription rules, effective immediately.

Chained proxy

On the Proxies page click "Chained proxy rules" in the toolbar to open the chain editor: saved chains on the left; on the right, build a chain by picking hops from all candidates, with drag-to-reorder, insert-between-hops, region filters and pinned favorites — each candidate shows recent latency, and a proxy group can only be the first hop. Chains can be any length and apply immediately via hot reload after saving. To quickly give a single node a front proxy, just click the chain button on its card. Chained latency is roughly the sum of all hops — usually slower, but potentially more stable.

Floating window and shortcuts

The traffic floating window is customizable in content and appearance:

ItemOptions
Sizecompact / standard / large.
Layoutcard / capsule / gauge.
Color themeauto (follows the main app) / graphite / aurora / sunset / emerald / midnight / ivory — 7 in total.
Display itemsCurrent node latency, active connections, mini traffic chart, today's traffic, system proxy status and mode — each toggleable.
OpacityDefault 88.

Default global shortcuts are listed in Settings: toggle the system proxy Ctrl+Shift+P, toggle TUN mode Ctrl+Shift+T, show the main window Ctrl+Shift+U, toggle the traffic floating window Ctrl+Shift+O and cycle the proxy mode Ctrl+Shift+M; "Update all subscriptions" and "Restart core" are unbound by default and can be recorded in Settings. Right-clicking the tray icon also opens a quick panel for toggling the system proxy or TUN, opening the main window and more; clicking the "node" or "group" row pops up a standalone node picker beside the panel — all proxy groups on the left, that group's nodes and latencies on the right, click to switch without digging through the small panel.

Global command palette

Press Ctrl+K (or click the search button in the sidebar) to bring up the command palette on any page; type keywords to filter the entries, or leave it empty to list every available action by group:

GroupWhat it does
PagesJump to any page in the app.
SettingsJump straight to any of the six settings tabs: Appearance / System / Network / Tools / Maintenance / About.
ActionsStart / stop / restart the core, toggle the system proxy, TUN mode, LAN connections and the floating window, switch light/dark themes and rule / global / direct modes, quit the app, and more.
SubscriptionUpdate all subscriptions; update, enable or disable a specific subscription; open the provider's website in one click when one is set.
MaintenanceCheck for core updates (upgrade in one click when one is found), check for app updates, update the GeoData database, export and import backups, back up to the cloud or restore from it (shown once WebDAV is configured), and reset rule-hit, app or node traffic statistics.
Network rescueOne-click rescue, flush the DNS cache, reset the system proxy and DNS servers, restore the hosts file, reset the network stack; risky actions ask for confirmation first.
ToolsOpen the web dashboard, the data directory and the log directory, export diagnostics, and open the official site or the User Guide.
NodesSearch existing nodes — results show recent latency, press Enter to switch (appears only after you type a keyword, keeping the list short for large subscriptions).

Keyboard: ↑ ↓ to select, Enter to run, Esc to close. Everyday moves like switching nodes or modes, checking for updates or restoring backups no longer need the mouse.
