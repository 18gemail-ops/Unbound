Unlock Test

Unlock Test visits 18 popular services through the current exit and reports Unlocked / Partial / Blocked / Failed for each, so you can tell whether this route can stream and use AI tools.

What this page solves

"I switched to a new node — can I still watch Netflix?" "ChatGPT suddenly won't sign in?" Questions like these do not need a website-by-website check. This page tests all 18 services in one pass and reports the results without delay. Requests leave through the local mixed port — the same proxy path your daily traffic takes — so what you see is the real result of the current exit node; switch to another route and the outcome can be completely different.

How to use it

  1. Pick the exit: the "Exit node" row at the top has two dropdowns — pick a group, then a node; you can switch right here, and each node shows its latency;
  2. Start a test: click "Test all" at the top right to check all 18 in parallel, or click the refresh icon on a single card to test just that service;
  3. Read the results: the subtitle summarizes "Unlocked N · Partial N · Tested N/18" in real time, and each card shows a status badge and a short note.

What the states mean

StatusMeaning
Not testedNot tested yet. Click the refresh icon on the card to run a single check.
UnlockedThe service is fully available through the current exit.
PartialReachable, but with limited content — the classic case is Netflix showing only its own productions.
BlockedClearly unavailable; the detail line shows the HTTP status code or the region notice.
FailedThe request itself did not complete (timeout, proxy unreachable, etc.) — this does not mean the service is unavailable. Check the core and node status first, then test again.

How the checks work

Every check sends requests through the local mixed port with a browser User-Agent and a 12-second timeout. Each service is judged differently:

  • Netflix: two titles are cross-checked — an original series first, and only if it returns 200, a non-original title. Both reachable means Unlocked; only the original means Partial; otherwise Blocked.
  • Disney+ / Prime Video / Spotify / TikTok: the home page loads and shows no "not available in your region" notice — Unlocked.
  • Hulu / HBO Max: a redirect to a region notice page, or restricted-content text on the page, means Blocked.
  • ChatGPT Web: a 403 response means the region is unsupported; ChatGPT iOS probes a long-stable mobile status endpoint instead.
  • Bilibili: an in-site API reports how Bilibili sees the exit region — mainland China gets the full catalogue, while Hong Kong, Macao, Taiwan and overseas regions are partially restricted.
  • Claude / Copilot / Gemini / X / iQIYI / Tencent Video / NetEase Cloud Music: home page reachability; region limits show up as a 403 or a redirect to a notice page.

In one sentence

Unlock Test does not ask "does this service exist" but "what happens right now when I reach it through this route". Results reflect the exit as of the moment they were measured — retest after switching nodes.
