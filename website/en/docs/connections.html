User Guide

Connections

The Connections page shows what's online right now and lets you create rules for domains on the fly — make a domain direct or route it through a chosen line immediately, without touching config files.

What this page solves

When you're unsure who's online or which line a site took, come here. It lists every connection the core is handling right now, so you can verify routing results and fix them in place: right-click a connection to create a rule for its domain.

Two views

Switch between two ways of viewing the page:

Detail view — one row per connection, ideal for inspecting a single connection. Columns:

ColumnMeaning
HostThe connection's destination hostname.
ProcessThe program that opened the connection.
NetworkThe network protocol in use — tcp or udp.
DestinationThe address actually visited.
RuleThe rule this connection matched.
ChainWhich line or proxy group the traffic took.
Up / DownData sent / received by this connection.
DurationHow long the connection has lasted.

Aggregated view — merges similar connections by domain / destination to reveal the overall picture. Columns: domain / destination, connections, process, rule, chain, up, down.

Create quick rules with right-click

Right-click any connection row to open a menu with:

  • Direct for this domain — traffic to this domain goes out directly, bypassing the proxy.
  • Route this domain through a chosen line — a submenu lists available proxy groups; pick one and the domain routes through it. With no groups available the submenu shows "No proxy groups available".
  • Copy domain — copies the connection's domain to the clipboard.
  • Copy destination — copies the connection's destination address.
  • Copy process path — copies the full path of the process that opened the connection.

How quick rules take effect

Choosing "Direct for this domain" or "Route this domain through a chosen line" creates a quick rule of type DOMAIN-SUFFIX. It's inserted at the very top of the rules when the runtime config is generated, so it outranks subscription rules and takes effect for that domain immediately — no core restart needed. To undo, right-click the domain again and pick a different line.

Two practical tips

Live speeds come from the core and disappear once a connection closes. With lots of data, use the search / filter above to narrow things down and find your target faster.
