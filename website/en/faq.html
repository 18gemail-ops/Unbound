FAQ

Start here — chances are you'll find your answer

Installation failures, connection issues, "where is that switch" — the guide covers them all; this page gathers the most frequently asked questions.

About the software itself

How does Unbound link relate to Clash-based clients?

Unbound link is a Windows desktop client whose networking power comes entirely from the mihomo core (the successor of the Clash Meta line) — it implements no proxy protocols itself. Its job is subscription management, runtime config generation, core lifecycle and supervision, and observing and controlling the core through its API.

Do I need to download and place the core myself?

No. The core (mihomo) and TUN driver ship with the installer, and the client starts and stops them. You don't edit config files by hand either — the runtime config is generated by the client from your subscription and settings.

The core itself can be checked and updated under Settings → Maintenance → Core update.

Is macOS or Linux supported?

Currently only 64-bit Windows 10 / 11. Some features (system proxy writes, the TUN virtual adapter, the tray and UAC elevation) rely on Windows capabilities.

Where do I get a subscription?

Subscriptions come from your own provider — the client bundles none and resells none. Once you have a link like https://…, paste it into Profiles → Add subscription.

Can I import multiple subscriptions?

You can import and keep multiple subscriptions, and drag cards to reorder them. Each subscription has its own enable switch — several can be on at once: the first enabled subscription supplies the base config (port / DNS / mode), while the others merge in their nodes, proxy groups and rules; the effective order follows the list from top to bottom. Changing what's enabled regenerates the runtime config.

Making the proxy work

The system proxy is on — why do some apps still bypass it?

That's the inherent limitation of system proxies: only programs that read Windows Internet settings (browsers, most desktop software) use it. Games, some command-line tools and apps with their own network stack ignore this setting.

Two fixes: enable TUN mode (the virtual adapter takes over all traffic at the network layer; admin rights required), or bind the process to a chosen line with App Routing.

Apps from the Microsoft Store can't reach the network — what should I do?

Windows blocks Store apps from accessing local addresses (127.0.0.1) by default, so they can't use the local proxy directly — the app shows no connectivity, spinning forever.

Go to Settings → Tools → UWP App Tool → Manage apps and flip the switch to lift the loopback restriction; this needs admin rights — if it fails, restart the app as administrator and try again.

System proxy, TUN mode or App Routing — which should I use?
  • System proxy: covers browsers and most software, needs no extra privileges — the everyday first choice.
  • TUN mode: covers all traffic, including apps that ignore the system proxy; requires admin rights.
  • App Routing: affects only bound processes — for singling out individual apps onto dedicated lines.

All three can be enabled at the same time without conflict.

What's the difference between Rule, Global and Direct modes?

Rule decides each connection's path from the subscription and your own rules — the everyday mode; Global ignores rules and sends everything through the selected exit; Direct bypasses the proxy entirely.

Switch under Settings → Network → Mode. Note: in Global or Direct mode, rules in the rule list no longer take effect.

Quick rules vs. subscription rules — which wins?

Quick rules. Domain rules you create by right-clicking on the Connections page are inserted at the very top of the rule list, so they match before subscription rules and take effect immediately — no core restart needed.

All nodes show as timed out — what now?

Check in order: ① On the Proxies page click "Test all" for the latest latencies; ② On the Profiles page click "Traffic" on the card to refresh usage info and confirm the subscription hasn't expired; ③ Click "Update" to re-fetch the subscription; ④ Check the "direct exit / proxy exit" and "current node" conclusions in Diagnostics.

For more scenarios see Troubleshooting.

Does switching nodes drop existing connections?

Switching nodes or changing DNS/ports applies to the core via hot reload — the core process itself is not restarted. Connections already in flight may be re-established because the exit changed; that's normal proxy behavior.

Privileges and data

Why do some operations require admin rights?

Operations that modify system-level settings require admin rights: enabling TUN mode, resetting DNS servers, restoring the hosts file and resetting the network stack. The client marks them clearly in the UI and elevates via UAC when executed — never silently.

Resetting the system proxy and flushing the DNS cache in one-click rescue need no admin rights and are always available.

Does the software collect or upload my data?

No account required, no telemetry. Settings, subscriptions, statistics and logs all live in the local data directory %APPDATA%\com.unboundlink.desktop.

The app makes only three kinds of outbound requests: fetching your subscription links, checking for and downloading core updates, and probe requests during Diagnostics and speed tests (e.g., 204 check endpoints and your own nodes).

Switching computers or reinstalling — how do I keep my setup?

Settings → Maintenance → Backup and restore → Export backup produces a JSON file with your settings, subscriptions, Merge config and core version. Install in the new environment and click "Import backup" to restore (this overwrites current settings and subscriptions).

I want to report a problem — what information helps most?

Settings → Maintenance → Backup and restore → Export diagnostics produces a ZIP with app and core versions, current settings, runtime config and recent logs — secrets and other sensitive fields are redacted automatically, so you can attach it directly to your report.

After uninstalling, my browser can't open pages?

That means the system proxy was still on at uninstall time and the browser is still pointing at the local proxy port. Fix: reinstall and click "One-click rescue" in Diagnostics → Network rescue (reset system proxy + flush DNS cache), or clear the proxy server in Windows Internet Options → Connections → LAN settings.

In the future, turn off the system proxy under Settings → System → System proxy before uninstalling.

Will uninstalling delete my settings and subscriptions?

No. The uninstaller only removes program files; the data directory stays. To clean up completely, delete %APPDATA%\com.unboundlink.desktop manually.

Usage details

Which ports are used by default? What if they're taken?

The default mixed proxy port is 7890 and the control API port is 9090. The "port listening" check in Diagnostics tells you whether the ports are properly listened on or taken by another program. Change them under Settings → Network → Ports and mode; the core restarts automatically after changes.

Why does the download speed test run only about 10 seconds — and switch nodes temporarily?

The gauge icon on a node card runs a download speed test; reflecting real bandwidth takes actual downloading, hence roughly 10 seconds. The test temporarily switches the exit to that node and restores the previously selected node when done. Results are cleared automatically after about 10 minutes so stale data doesn't mislead.

Why do the logs have two sources?

Logs from the core itself (connections, rule matching, etc.) come over the core's live channel; the client's own operation logs (subscription updates, config reloads, core start/stop, etc.) carry a [Unbound link] prefix. Both appear together in time order on the Logs page, and level filters apply to both.

Where does the app go when I close the window?

By default "minimize to tray on close" is on — the close button only hides the window and the proxy keeps running. Right-click the tray icon to reopen the main window or exit completely. This behavior can be changed under Settings → System → Tray and watchdog.

How do I customize the floating window — and will it block mouse clicks?

The floating window offers 3 sizes, 3 layouts (card / capsule / gauge) and 7 color themes; latency, connection count, traffic chart, today's traffic and proxy status can each be toggled, and opacity adjusted. If clicks bother you, enable "mouse pass-through" under Settings → System → Tray and watchdog.

Are there keyboard shortcuts?

Five global shortcuts by default: Ctrl+Shift+P toggles the system proxy, Ctrl+Shift+T toggles TUN mode, Ctrl+Shift+U shows the main window, Ctrl+Shift+O toggles the traffic floating window and Ctrl+Shift+M cycles the proxy mode (Rule → Global → Direct). "Update all subscriptions" and "Restart core" are unbound by default and can be recorded. Find them under Settings → System → Global shortcuts; record your own or reset to defaults.

Still stuck?

Check the Troubleshooting and Diagnostics chapters of the guide first; if that doesn't help, open an issue in the repository — including error lines from the Logs page and the Diagnostics conclusions speeds up the investigation.
