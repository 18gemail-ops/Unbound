使用手册

规则列表

「规则列表」页回答「什么流量走哪条线」：它列出当前正在生效的规则、订阅里引用的规则集，以及每条规则实际被命中的次数。

四个页签

页面顶部有四个页签：规则列表、自定义规则、规则集、命中统计。它们看的是同一套规则的不同侧面——「有哪些规则」「我想额外加哪些规则」「规则从哪来」「规则用得怎么样」。切换页签即可查看，不必离开本页。

规则列表

默认展示的第一个页签，列出当前运行时配置里的全部规则。数据来自内核真正读取的那份配置，也就是你把订阅和覆写合成后的结果。表格共四列：

列含义
类型规则的匹配类型，例如 DOMAIN-SUFFIX、GEOIP 等。
匹配内容这条规则要匹配的域名、IP 段或地区。
策略（出口）命中这条规则后，流量从哪个出口出去，通常是一个代理组、一个节点名，或 DIRECT、REJECT 一类的内置策略。
命中（命中次数）这条规则累计被命中多少次。

规则数量往往很多，上方提供了筛选与搜索：可按类型筛选，也可按关键词搜索匹配内容。结果较多时会自动分页，方便定位特定的一条。

自定义规则

「自定义规则」页签是一个可视化编辑器：不用手写配置文件，在这里增删改自己的分流规则，点「保存并应用」后按列表顺序注入运行配置的规则最前，优先级高于快捷规则与订阅规则。

编辑是草稿式的：所有改动先停留在页面上，出现「放弃修改」按钮与「有未保存的修改」提示，只有点「保存并应用」才会写入并热重载内核；点「放弃修改」则恢复为已保存的状态。表格展示草稿中的全部规则，共六列：#（顺序）、类型、匹配内容、策略、附加参数、操作。每行的操作区有四个按钮：上移、下移、编辑、删除；越靠上优先级越高，第一行的上移与最后一行的下移不可用。

点「新增规则」或行内的编辑按钮弹出表单，共四项：

字段说明
规则类型如 DOMAIN-SUFFIX、GEOSITE、IP-CIDR 等；可直接输入，也可从常用类型建议中选择，自动转为大写。
匹配内容规则要匹配的域名、IP 段或地区。选择 MATCH 类型时不需要填写。
目标策略命中后的出口：DIRECT、REJECT，或内核当前的策略组与节点名（可从建议列表选择）。
no-resolve仅对 IP 类规则（IP-CIDR、GEOIP 等）显示；开启后这类规则跳过域名解析，减少不必要的 DNS 查询。

规则类型限定为大写字母、数字与连字符，匹配内容与目标策略里不能包含逗号或换行；保存时任一条规则校验不通过，会拒绝整次保存并指出是第几条。自定义规则最多 200 条。

MATCH 规则会「截断」后面的规则

自定义规则插入的是规则列表最前，而匹配顺序是从前往后、一旦命中就不再往下走。如果把一条 MATCH 规则排在最前，它后面的所有规则都不会再被命中。

规则集

规则集页签列出订阅里引用的规则集，也就是 rule-provider。规则集把一大批规则打包成外部文件，让主配置更精简；订阅引用它们之后，这些规则同样参与匹配。表格共五列：

列含义
名称规则集的标识名。
类型规则集的类型。
行为规则集的匹配行为。
规则数该规则集包含多少条规则。
更新时间该规则集最近一次更新的时间。

命中统计

命中统计页签把规则按实际使用情况呈现出来，表格共四列：类型、匹配内容、出口、命中次数。它让你看出哪些规则在真正起作用。

这些数据由客户端在内核运行后每 15 秒采样一次连接记录并累计落盘，因此刚启动软件时可能显示「暂无统计数据（内核运行后每 15 秒采样一次）」，稍等片刻就会陆续出现。统计会持久保存，重启软件不会清零。

分流模拟

规则列表页的工具区有一个「分流模拟」按钮：输入一个域名、IP 或进程名，就能在本地预演它会命中哪一条规则，并显示该规则的处理策略。它不需要内核运行，排查「为什么这个网站走了那条线」时很实用。

模拟器支持两种输入：域名 / IP 按域名类与 IP 类规则匹配；应用进程按进程规则匹配（如 chrome.exe）。结果会标出命中的规则序号、规则原文与处理策略；如果目标是策略组，还会解析出该组当前的出口节点。

少数规则无法在本地精确判断（如依赖 GeoSite / GeoIP 数据、正则或需要先解析域名的规则），模拟器会把它们如实列出并跳过，而不是给出错误结论；如果你输错格式，也会有相应提示。所有判断都基于当前生成的运行时配置，与内核实际使用的是同一份规则。

规则优先级

规则的生效顺序是从上到下匹配，先命中先用。运行时配置里规则的排布顺序为：自定义规则（规则页编辑器编排）→ 快捷规则（实时连接页右键创建）→ 订阅规则。应用内生成的两类规则都插在订阅规则之前，其中自定义规则的优先级最高。此外，应用分流的绑定是按进程匹配，也在配置生成阶段生效。

改了规则却没变化？

先检查当前运行模式是否为「规则」：设置 → 网络 → 运行模式。「全局」模式下所有流量都走同一个出口，规则不会生效。
