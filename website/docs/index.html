使用手册

手册总览

这份手册按客户端的 11 个功能页逐页讲解：每个页面能做什么、参数怎么填、改坏了怎么恢复。第一次使用建议从「安装与首次运行」开始。

五分钟上手路径

安装 → 导入订阅 → 打开订阅的启用开关 → 打开系统代理 → 在仪表盘确认节点已连通。就这五步。

先认识几个名词

后面的章节会反复用到这几个词，先花一分钟建立印象：

名词含义
内核真正干活的程序（mihomo）。它会随安装包一起装好，由客户端负责启动、守护和停止，你不需要单独安装或配置它。
订阅一条 http/https 链接，打开后是一份 YAML 配置，里面包含节点、策略组和规则。客户端把它下载到本地，作为生成运行时配置的原材料。
节点 / 代理组节点是单条线路；代理组是一组节点的集合，可以按延迟自动选、手动切或做故障转移。
规则「什么流量走哪条线」的判断依据。命中最后一条都匹配不上时，走订阅里的兜底策略（通常是 MATCH）。
系统代理修改 Windows 的 Internet 设置，让支持系统代理的程序（浏览器、多数桌面软件）自动走代理。需要内核正在运行。
TUN 模式创建虚拟网卡，把全部流量在网络层接管，能覆盖不认系统代理的程序（部分游戏、命令行工具）。需要管理员权限。
运行时配置客户端把「订阅 + 你的覆写 + 应用级设置」合成的那份 config.yaml，是内核真正读取的文件。它不由你直接编辑。

手册目录

开始

  • 安装与首次运行 —— 系统要求、安装步骤、数据目录位置、第一次配置要做的事。

功能详解（对应界面左侧菜单）

  • 仪表盘 —— 总览状态，切换代理组与节点。
  • 订阅管理 —— 添加、更新、排序订阅，多订阅同时启用，导入节点链接，Merge 覆写与扩展脚本。
  • 代理节点 —— 切换节点、测速、收藏、地区筛选、链式代理，可一键隐藏超时节点。
  • 应用分流 —— 让指定应用走指定线路。
  • 规则列表 —— 查看生效规则、规则集与命中统计。
  • 实时连接 —— 查看谁在联网，为域名创建快捷规则。
  • 流量统计 —— 按日查看上下行用量。
  • 运行日志 —— 排查看日志，按级别筛选，可落盘到文件。
  • 网络体检 —— 11 项体检与断网急救箱。
  • 解锁测试 —— 18 项服务的解锁检测，判断当前线路的流媒体与 AI 可用性。
  • 设置 —— 端口、模式、TUN、DNS、UWP 工具、GeoData 更新、流量隧道、节点整理、快捷键、主题定制、应用日志、备份与诊断导出。

进阶与帮助

  • 进阶技巧 —— Merge 写法、扩展脚本示例、快捷规则、命令面板、悬浮窗与快捷键。
  • 故障排查 —— 常见故障的现象、原因与处理顺序。

设置项都在哪里

遇到「某个开关找不到」时，先看这张对照表，绝大多数开关都在「设置」的六个页签里：

页签管什么
外观主题、语言、失焦暂停渲染、代理页列数、隐藏超时节点、主题定制（颜色 / 字体 / 自定义 CSS）。
系统系统代理（含绕过列表、终端代理命令）、开机自启、静默启动、启动页面、启动脚本、托盘点击事件、托盘图标三态、关闭时最小化到托盘、流量悬浮窗、悬浮窗鼠标穿透、系统通知、内核看门狗、启动时检查更新、切换节点自动清理连接、系统代理守卫、全局快捷键。
网络端口与模式（混合代理端口、控制端口、运行模式、日志级别）、内核行为（自动启动内核、允许局域网连接、IPv6、统一延迟）、Web 控制面板（含控制密钥）、TUN 模式、自定义 DNS（含备用 DNS 与静态 Hosts）、测速与健康（定时延迟检测、节点健康监控、掉线自动切换）、网络环境（按 Wi-Fi 名称自动切换系统代理与运行模式）。
工具UWP 应用工具、GeoData 数据库、流量隧道、节点整理。
维护订阅自动更新间隔、内核更新、节点测速地址与超时、应用日志、备份与恢复（含导出诊断信息）。
关于应用 logo 与应用名、应用版本、内核版本、数据目录（可一键打开）、帮助与支持（软件官网与在线使用手册）、开发者工具、退出应用。
设置是即时生效的

所有设置项修改后立刻保存，没有「确定 / 应用」按钮。涉及内核的改动（如端口、TUN、DNS）会自动重载或重启内核，界面上的开关状态以实际生效结果为准。
