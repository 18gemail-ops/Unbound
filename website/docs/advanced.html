使用手册

进阶技巧

这一页给出六个常用技巧：用 Merge 与脚本微调订阅、为域名建快捷规则、让受限节点经中转连接、用命令面板快速跳转，以及把悬浮窗和快捷键调顺手。

Merge 覆写怎么用

在「订阅管理」页点开「全局扩展覆写配置」，在弹出的编辑框里写 YAML 片段。生成运行时配置时，这段内容会与订阅内容递归深度合并，用来覆盖订阅里的字段；只写你要改的片段即可，不需要抄整份配置，订阅自身更新也不受影响。

端口、控制密钥、运行模式与日志级别不要写在这里

这几项属于应用级设置，由客户端在生成配置时统一写入，会覆盖 Merge 里的同名内容。要改它们请到「设置 → 网络 → 端口与模式」。

下面这段同时做了三件事：打开统一延迟，追加一段 dns 配置，并为名为「手动切换」的代理组补充一个节点。

unified-delay: true

dns:
  enable: true
  nameserver:
    - 223.5.5.5

proxy-groups:
  - name: 手动切换
    type: select
    proxies:
      - 香港节点 01

扩展脚本示例

同页的「全局扩展脚本」支持在编辑框里写 QuickJS 脚本，脚本必须实现 main(config) 并 返回 config。客户端用内置 QuickJS 引擎执行，可以批量改写节点名、增删规则。下面两段可直接粘贴使用。

示例一：去掉节点名里的广告词。

function main(config){
  config.proxies.forEach(p => {
    p.name = p.name.replace(/官网|订阅/g, "")
  })
  return config
}

示例二：给所有节点名加统一前缀。

function main(config){
  config.proxies.forEach(p => {
    p.name = "[U] " + p.name
  })
  return config
}

快捷规则

在「实时连接」页右键某条连接，选择「此域名直连」或「此域名走指定线路」。客户端会据此生成一条 DOMAIN-SUFFIX 规则，并插入到规则列表最前，优先级高于订阅规则，立即生效。

链式代理

在「代理节点」页点工具区的「链式代理规则」，打开链路编辑器：左侧列出已保存的链路，右侧从全量候选里点选环节搭链，支持拖拽排序、环节间插入、按地区筛选与收藏置顶，候选右侧显示节点近期延迟，代理组只能作为第一环。链路可任意长，保存后立即热重载生效。如果只想给单个节点快速指定前置，也可以直接在节点卡片上点链式按钮设置。链式之后延迟约为各段之和，通常会更慢一些，但可能更稳。

全局快捷键的默认值见设置：切换系统代理 Ctrl+Shift+P、切换 TUN 模式 Ctrl+Shift+T、显示主窗口 Ctrl+Shift+U、开关流量悬浮窗 Ctrl+Shift+O、切换代理模式 Ctrl+Shift+M；「更新全部订阅」与「重启内核」默认未绑定，可在设置里自行录制。托盘图标右键还能弹出快捷面板，用来切换系统代理、TUN、打开主窗口等；点击面板中的「节点」或「分组」行，会在面板旁边弹出独立的节点选择浮层——左栏列出全部代理分组，右栏列出该分组的节点与延迟，点选即切换，无需在狭小的面板内翻找。
