下载地址为 GitHub Releases 页面。安装包会请求网络与文件读写权限，安装前请确认来源可信。

安装前请确认

  • 系统为 64 位 Windows 10 或 Windows 11。
  • 使用系统代理无需额外权限；使用 TUN 模式需要管理员权限，届时会弹出 UAC 确认。
  • 如果电脑上已装其他使用相同内核的客户端，请先退出其中之一，避免控制端口冲突。
  • 默认占用端口：混合代理 7890、控制接口 9090，可在设置中修改。

安装后建议

  • 先到「订阅管理」添加订阅，再打开卡片上的启用开关。
  • 在「设置 → 常规 → 系统集成」打开系统代理。
  • 回「仪表盘」确认内核运行中、节点有延迟数值。
安装步骤

三步装好，五步用起来

下载安装包

打开官方发布页，在最新版本中下载 Windows 安装包（文件名形如 Unboundlink_x.x.x_x64-setup.exe）。

运行安装向导

双击安装包，选择安装位置后一路下一步即可。建议使用默认安装目录，避免放在含中文或特殊字符的路径下。

首次启动

从开始菜单或桌面图标启动。若检测到历史版本的数据目录，客户端会自动迁移旧设置与订阅，无需手动搬运文件。

导入订阅并启用

「订阅管理」→「添加订阅」→ 粘贴 http/https 订阅链接 → 确定；回到卡片打开启用开关（可同时启用多个订阅）。

打开系统代理

「设置 → 常规 → 系统集成」打开「系统代理」，然后到「仪表盘」确认下载、上传数值开始变化。

数据与卸载

你的数据放在哪，怎么带走

数据目录

配置、订阅与内核工作目录位于 %APPDATA%\com.unboundlink.desktop，包含设置、订阅索引与订阅原文、Merge 覆写、扩展脚本、生成的运行时配置、内置面板文件、规则命中统计与流量历史。

在「设置 → 关于」里可以直接查看并复制数据目录路径。

备份、迁移与卸载

换电脑前用「设置 → 维护 → 备份与恢复 → 导出备份」导出一个 JSON 文件，新环境导入即可恢复设置、订阅、Merge 配置与内核版本记录。

卸载程序不会自动删除数据目录；如需彻底清理，卸载后手动删除上述目录即可。

卸载前记得关闭系统代理

先在「设置 → 常规 → 系统集成」关闭「系统代理」，或使用「网络体检 → 断网急救箱 → 一键急救」重置系统代理，避免卸载后浏览器仍然指向已经不存在本机代理端口。
