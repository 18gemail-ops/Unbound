关于软件本身

无界互联和 Clash 系列客户端是什么关系？

无界互联是一个 Windows 桌面客户端，网络能力全部来自 mihomo 内核（Clash Meta 系列的延续），自身不实现任何代理协议。它负责的是订阅管理、运行时配置生成、内核启停与守护，以及通过内核接口做观测与操控。

需要自己下载和放置内核吗？

不需要。内核（mihomo）与 TUN 驱动随安装包一起分发，由客户端负责启动和停止。你也不需要手动编辑配置文件——运行时配置由客户端根据订阅与你的设置生成。

内核本身也可以在「设置 → 维护 → 内核更新」里检查并更新到新版本。

支持 macOS 或 Linux 吗？

目前仅支持 Windows 10 / 11 64 位。部分功能（系统代理写入、TUN 虚拟网卡、托盘与 UAC 提权）依赖 Windows 系统能力。

从哪里获取订阅？

订阅由你自己的服务商提供，客户端不附带也不代购任何订阅。拿到形如 https://… 的订阅链接后，在「订阅管理 → 添加订阅」里粘贴即可。

可以同时导入多个订阅吗？

可以导入并保留多个订阅，卡片可拖动排序。每个订阅的启用开关独立控制，可以同时启用多个：第一个启用的订阅提供端口 / DNS / 模式等基础配置，其余订阅的节点、策略组与规则并入，生效顺序按列表从上到下；启用状态变化后会重新生成运行时配置。

关于代理生效

开了系统代理，为什么有些软件还是不走代理？

这是系统代理的固有局限：只有读取 Windows Internet 设置的程序（浏览器、多数桌面软件）才会使用它。游戏、部分命令行工具和应用内自建网络栈的程序不会读取这个设置。

两种解决办法：开启 TUN 模式（虚拟网卡在网络层接管全部流量，需要管理员权限），或用 应用分流 把该进程绑定到指定线路。

Microsoft Store 安装的应用连不上网怎么办？

Windows 默认禁止应用商店安装的应用访问本机地址（127.0.0.1），因此它们无法直接使用本机代理，表现为应用内网络不通、一直转圈。

到「设置 → 工具 → UWP 应用工具 → 管理应用」，为它打开开关解除回环限制即可；这个操作需要管理员权限，若失败请以管理员身份重启应用后重试。

系统代理、TUN 模式、应用分流，到底该用哪个？
  • 系统代理：覆盖浏览器等大多数软件，不需要额外权限，日常首选。
  • TUN 模式：覆盖全部流量，包括不认系统代理的程序；需要管理员权限。
  • 应用分流：只影响被绑定的进程，用来给个别应用指定专门线路。

三者可以同时开启，互不冲突。

运行模式里的「规则」「全局」「直连」有什么区别？

规则按订阅与你自己添加的规则决定每条流量走哪条线，是日常使用的模式；全局忽略规则，所有流量都走当前选中的出口；直连则全部不走代理。

在「设置 → 网络 → 运行模式」切换。需要注意：切换到「全局」或「直连」后，规则列表里的规则不会生效。

快捷规则和订阅里的规则冲突时，谁生效？

快捷规则优先。你在「实时连接」页右键创建的域名规则会被插入到规则列表的最前面，因此先于订阅里的规则被匹配，且立即生效、无需重启内核。

节点显示全部超时怎么办？

按顺序排查：① 在「代理节点」页点「全部测速」确认最新延迟；② 在「订阅管理」页点订阅卡片上的「流量」刷新用量信息，确认订阅未过期；③ 点「更新」重新拉取订阅；④ 到「网络体检」查看「直连出口 / 代理出口」与「当前节点」的结论。

更多场景见 故障排查。

切换节点会让已有连接断开吗？

切换节点、修改 DNS 或端口这类改动会通过热重载应用到内核，不会重启内核进程本身。已经在传输的连接可能因出口变化而重新建立，这是代理的正常行为。

关于权限与数据

为什么有些操作要求管理员权限？

需要改动系统级设置的操作会要求管理员权限：开启 TUN 模式、重置 DNS 服务器、恢复 hosts 文件、重置网络协议栈。客户端会在界面上明确标注，并在执行时通过 UAC 提权，不会静默提权。

而「一键急救」里的重置系统代理与刷新 DNS 缓存不需要管理员权限，随时可以点。

软件会收集或上传我的数据吗？

不需要账号，也不做数据上报。设置、订阅、统计与日志全部保存在本机的数据目录 %APPDATA%\com.unboundlink.desktop。

程序产生的对外网络请求只有三类：拉取你的订阅链接、检查与获取内核更新、以及网络体检与测速时的探测请求（例如访问 204 检测地址与你的节点）。

换电脑或重装系统，怎么把配置带走？

「设置 → 维护 → 备份与恢复 → 导出备份」，会把设置、订阅、Merge 配置与内核版本导出为一个 JSON 文件。在新环境安装后点「导入备份」即可恢复（会覆盖当前设置与订阅）。

想反馈问题，怎么提供信息最有用？

「设置 → 维护 → 备份与恢复 → 导出诊断信息」会生成一个 ZIP 包，内含应用与内核版本、当前设置、运行配置与最近的日志，密钥等敏感字段已自动打码，可直接附在问题反馈里。

卸载后浏览器打不开网页了？

说明卸载时系统代理仍处于开启状态，浏览器还在指向本机的代理端口。处理方式：重新安装并在「网络体检 → 断网急救箱」里点「一键急救」（重置系统代理 + 刷新 DNS 缓存），或在 Windows「Internet 选项 → 连接 → 局域网设置」里取消代理服务器。

以后卸载前，先在「设置 → 系统 → 系统代理」关闭「系统代理」即可。

卸载会删除我的设置和订阅吗？

不会。卸载程序只移除程序文件，数据目录会保留。如果需要彻底清理，手动删除 %APPDATA%\com.unboundlink.desktop 即可。

关于使用细节

默认占用哪些端口？被占用怎么办？

默认混合代理端口为 7890，控制接口端口为 9090。「网络体检」的「端口监听」项会告诉你端口是被正常监听还是被其他程序占用。改端口在「设置 → 网络 → 端口与模式」，修改后内核会自动重启。

「下载测速」为什么只测 10 秒，还临时换了节点？

节点卡片上的仪表图标是下载测速，需要真实下载一段时间才能反映带宽，因此固定约 10 秒。测速会把当前出口临时切到该节点，测完自动恢复原来选中的节点。测速结果约 10 分钟后自动清除，避免用旧数据误导判断。

日志里为什么有两套来源？

内核自身产生的日志（连接、规则匹配等）来自内核的实时通道；客户端自身的操作日志（订阅更新、配置重载、内核启停等）带 [无界互联] 前缀。两者在「运行日志」页按时间排列在一起，按级别筛选时统一生效。

关闭窗口后程序去哪了？

默认「关闭时最小化到托盘」是开启的，点关闭按钮只是隐藏窗口，代理仍在运行。从托盘图标右键菜单可以重新打开主界面或彻底退出。这个行为可以在「设置 → 系统 → 托盘与守护」里关闭。

悬浮窗怎么调样式，会不会挡住鼠标操作？

悬浮窗支持 3 档尺寸、3 种版式（卡片 / 胶囊 / 仪表）和 7 套配色，可以分别开关延迟、连接数、流量曲线、今日流量与代理状态的显示，还能调整不透明度。担心挡操作就在「设置 → 系统 → 托盘与守护」打开「悬浮窗鼠标穿透」。

有快捷键吗？

默认五个全局快捷键：Ctrl+Shift+P 切换系统代理、Ctrl+Shift+T 切换 TUN 模式、Ctrl+Shift+U 显示主窗口、Ctrl+Shift+O 开关流量悬浮窗、Ctrl+Shift+M 切换代理模式（规则 → 全局 → 直连）；另有「更新全部订阅」「重启内核」两个动作默认未绑定，可自行录制。位置在「设置 → 系统 → 全局快捷键」，可自行录制修改或一键恢复默认。

还有问题没解决？

先看手册的 故障排查 与 网络体检 两节；仍未解决可以在仓库的 Issues 里反馈，附上「运行日志」页的报错行与「网络体检」的结论会更快定位。
