// 无界互联 · 扩展脚本（内置 QuickJS 引擎）
function main(config) {
  config.proxies = config.proxies.map(p => ({
    ...p,
    name: `[无界] ${p.name}`
  }));
  return config;
}

一个 main(config) 函数就能批量改写节点名、增删规则，改完自动热重载，不需重启内核。

04 / PROCESS

四步，从想法到上线

每一步都有明确的产出，你会一直知道项目走到哪了。

  1. 01

    沟通需求

    先说清楚要做什么、给谁用、什么时候要。评估可行性与工作量，给出口径明确的建议。

  2. 02

    方案与报价

    给出方案说明、功能清单、时间节点与固定报价。确认后再开工，不做中途加价的糊涂账。

  3. 03

    设计开发

    分阶段交付里程碑，随做随看。每个阶段都能看到真实进度，随时可以提意见调整。

  4. 04

    上线与维护

    部署上线、交付源码与说明文档，并提供后续的维护与迭代支持。

全栈自研，不转包设计、前端、后端、桌面端都在团队内部完成，沟通链路短，问题不踢皮球。
本地优先，数据可控默认把数据留在用户自己的机器上，该上云的场景才上云。
交付即用，不是 Demo交付能装上、能打开、能用的成品，附使用说明。
长期维护，持续迭代提供后续维护支持，我们自己的产品也在长期养。
